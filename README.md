# Хүүхдийн бүтээл

Хүүхдийн зурсан зураг, гар урлалын бүтээлийг зургаар нь оруулж, багш болон эцэг эх дүгнэлт өгдөг вэб систем.

## Боломжууд

- **Бүтээл оруулах**: зургаа сонгох эсвэл чирж оруулна (JPG, PNG, WEBP, GIF, 10MB хүртэл). Хүүхдийн нэр, нас/бүлэг, бүтээлийн нэр, тайлбар бичнэ.
- **Дүгнэлт өгөх**: 4 шалгуурт 1-5 одоор үнэлнэ.
  - Бүтээлч сэтгэлгээ
  - Өнгө хэрэглээ
  - Гүйцэтгэл, ур чадвар
  - Хичээл зүтгэл, нямбай байдал

  Мөн "Сайн тал", "Зөвлөмж" гэсэн тайлбар бичиж, дүгнэсэн хүний нэрийг оруулна. Нэг бүтээлд хэд хэдэн хүн дүгнэлт өгч болно.
- **Дундаж оноо**: шалгуур бүрийн болон нийт дундаж оноог автоматаар тооцоолно.
- **Галерей**: бүх бүтээлийг харж, хүүхдийн нэрээр шүүх эсвэл хайх боломжтой. Хүүхэд бүрийн бүтээлийн тоо, дундаж оноо харагдана.
- Бүтээл болон дүгнэлтийг устгах боломжтой.

## Ажиллуулах

Node.js 22.5 буюу түүнээс шинэ хувилбар хэрэгтэй (суурилагдсан `node:sqlite` ашигладаг).

```bash
npm install
npm start
```

Дараа нь http://localhost:3000 хаягаар орно. Портыг `PORT=8080 npm start` гэж өөрчилж болно.

Тест ажиллуулах:

```bash
npm test
```

## Бүтэц

| Файл | Үүрэг |
| --- | --- |
| `server.js` | Express сервер, API |
| `db.js` | SQLite хүснэгтүүд (`works`, `evaluations`) |
| `public/` | Вэб интерфэйс (HTML, CSS, JS) |
| `data/app.db` | Өгөгдлийн сан (автоматаар үүснэ) |
| `uploads/` | Оруулсан зургууд (автоматаар үүснэ) |

## API

| Арга | Зам | Тайлбар |
| --- | --- | --- |
| GET | `/api/works?child=&q=` | Бүтээлүүдийн жагсаалт |
| POST | `/api/works` | Бүтээл оруулах (multipart: `image`, `child_name`, `title`, `age_group`, `description`) |
| GET | `/api/works/:id` | Бүтээл, дүгнэлтүүд, дундаж оноо |
| DELETE | `/api/works/:id` | Бүтээл устгах |
| POST | `/api/works/:id/evaluations` | Дүгнэлт нэмэх (JSON: `creativity`, `color`, `technique`, `effort` = 1-5, `strengths`, `suggestions`, `evaluator`) |
| DELETE | `/api/evaluations/:id` | Дүгнэлт устгах |
| GET | `/api/children` | Хүүхэд бүрийн нэгтгэл |

> Анхааруулга: одоогоор нэвтрэх эрх (login) байхгүй. Интернэтэд нээлттэй байршуулах бол нэвтрэлт нэмэх шаардлагатай.
