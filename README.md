# Хүүхдийн бүтээл

Хүүхдийн зурсан зураг, гар урлалын бүтээлийг зургаар нь оруулж, багш болон эцэг эх дүгнэлт өгдөг вэб систем.

## Хөтөлбөртэй холбосон байдал

Систем нь **Сургуулийн өмнөх боловсролын сургалтын хөтөлбөр (2025)**-ийн **10.6. Зураг, урлал** сургалтын чиглэл болон **Долоо. Үнэлгээ** бүлэгт тулгуурласан. Хөтөлбөрийн өгөгдөл `curriculum.js` файлд байгаа.

| Хөтөлбөрт | Системд |
| --- | --- |
| Шаталсан түвшин (I–IV) | Бүтээл бүрийг аль түвшинд хамаарахыг сонгоно |
| Ай 1. Мэдрэх, илэрхийлэх; Ай 2. Хийж гүйцэтгэх (Зураг, Урлал) | Суралцахуйн 28 үр дүн (`ЗУ1.1а` … `ЗУ4.2е`). Бүтээл оруулахдаа холбогдох үр дүнг сонгоно |
| Үнэлгээний хүрээ: мэдлэг ойлголт, чадвар гүйцэтгэл, төлөвшил | Зураг, урлалын 11 үнэлгээний шалгуурыг ажигласан үедээ тэмдэглэнэ (заавал биш) |
| Үнэлгээний төрөл: гарааны, явцын, үр дүнгийн | Дүгнэлт бүрт төрлийг сонгоно |
| Арга, хэрэгсэл: ажиглалт, ярилцлагын тэмдэглэл, хувийн хавтас… | Дүгнэлт бүрт аргыг сонгоно |
| Хувийн хавтас, ахиц өөрчлөлтийг тодорхойлох | Хүүхэд бүрийн хувийн хавтас: хөтөлбөрийн хүснэгтийн бүтцээр үр дүн бүрийн сүүлийн дүгнэлт, давтамж, шалгуурын ахицын түүх. Хэвлэж болно |

**Ахицын хэмжүүр.** Хөтөлбөрт тоон оноо заагаагүй. Харин ахицыг урамшуулах, хүүхдийг харьцуулахгүй байх зарчим тавьсан. Тиймээс од, оноо биш, 3 шаттай хэмжүүр ашиглана: *Хөгжиж байна*, *Хүрсэн*, *Давж гүйцэтгэсэн*. Өөрчлөх бол `curriculum.js` доторх `RATINGS`-ийг засна.

## Боломжууд

- **Бүтээл оруулах**: зураг (JPG, PNG, WEBP, GIF, 10MB хүртэл), хүүхдийн нэр, нас/бүлэг, бүтээлийн нэр, хүүхдийн өөрийнх нь тайлбар, хөтөлбөрийн түвшин, холбогдох суралцахуйн үр дүн.
- **Дүгнэлт өгөх**: сонгосон үр дүн бүрийг үнэлж, шаардлагатай бол шалгуурыг тэмдэглэнэ. Мөн "Ахиц, давуу тал", "Дараагийн алхам, дэмжлэг" бичнэ. Нэг бүтээлд олон удаа (жишээ нь эхлээд гарааны, дараа нь явцын) дүгнэлт өгч болно.
- **Галерей**: хүүхэд, түвшин, түлхүүр үгээр шүүнэ. Карт дээр үр дүнгийн код, сүүлийн дүгнэлтээр хэдэн үр дүнд хүрснийг харуулна.
- **Хувийн хавтас** (хүүхдийн нэрийн хажуугийн 📁): хүүхдийн ахицыг хөтөлбөрийн түвшин тус бүрээр харуулна. Эцэг эхэд хэвлэж өгч болно.

## Ажиллуулах

Node.js 22.5 буюу түүнээс шинэ хувилбар хэрэгтэй (суурилагдсан `node:sqlite` ашигладаг).

```bash
npm install
npm start
```

Дараа нь http://localhost:3000 хаягаар орно. Портыг `PORT=8080 npm start` гэж өөрчилж болно.

Тест ажиллуулах:

```bash
npm test
```

## Бүтэц

| Файл | Үүрэг |
| --- | --- |
| `server.js` | Express сервер, API |
| `curriculum.js` | Хөтөлбөрийн суралцахуйн үр дүн, шалгуур, үнэлгээний төрөл |
| `db.js` | SQLite хүснэгтүүд (`works`, `assessments`, `assessment_scores`) |
| `public/` | Вэб интерфэйс (HTML, CSS, JS) |
| `data/app.db` | Өгөгдлийн сан (автоматаар үүснэ) |
| `uploads/` | Оруулсан зургууд (автоматаар үүснэ) |

## API

| Арга | Зам | Тайлбар |
| --- | --- | --- |
| GET | `/api/curriculum` | Хөтөлбөрийн өгөгдөл |
| GET | `/api/works?child=&level=&q=` | Бүтээлүүдийн жагсаалт |
| POST | `/api/works` | Бүтээл оруулах (multipart: `image`, `child_name`, `title`, `level`, `outcomes` (олон), `age_group`, `description`) |
| GET | `/api/works/:id` | Бүтээл ба дүгнэлтүүд |
| DELETE | `/api/works/:id` | Бүтээл устгах |
| POST | `/api/works/:id/assessments` | Дүгнэлт (JSON: `type` = initial/formative/summative, `outcomes` = {код: 1-3}, `criteria` = {K1…A3: 1-3}, `method`, `evaluator`, `strengths`, `next_steps`) |
| DELETE | `/api/assessments/:id` | Дүгнэлт устгах |
| GET | `/api/children` | Хүүхэд бүрийн нэгтгэл |
| GET | `/api/children/:name/portfolio` | Хүүхдийн хувийн хавтас |

> Анхааруулга: одоогоор нэвтрэх эрх (login) байхгүй. Интернэтэд нээлттэй байршуулах бол нэвтрэлт нэмэх шаардлагатай.
