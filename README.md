# Цэцэрлэгийн жилийн төлөвлөгөө бичих систем

Цэцэрлэгийн **4 бүлгийн** (бага, дунд, ахлах, бэлтгэл) хичээлийн жилийн сургалтын үйл
ажиллагааны төлөвлөгөөг 7 чиглэлээр (Нийгэм-сэтгэл хөдлөл, Хөдөлгөөн эрүүл мэнд, Хэл яриа,
Байгаль нийгмийн орчин, Математик, Зураг урлал, Хөгжим) хөтлөх, засах, хэвлэх систем.

## Ашиглах

`index.html` файлыг хөтөч (Chrome, Edge, Firefox) дээр нээхэд л болно. Интернет шаардлагагүй.

- **Бүлэг сонгох** — дээд талын 4 таб.
- **Тойм** — чиглэл бүрийн үр дүн, уялдаа, давтамжийн тоо, сар бүрийн ачаалал.
- **Чиглэл** — эх баримттай ижил хүснэгт. Сарын нүдэн дээр дарж
  *хэрэгжүүлэхгүй / давтамж (ногоон) / уялдаа (цэнхэр)* сонгоно. Уялдаа сонгоход тухайн
  бүлгийн бусад чиглэлийн үр дүнгээс жагсаалтаар сонгох ба “Уялдах суралцахуйн үр дүн”-гийн
  текст автоматаар бичигдэнэ. Уялдаа/давтамжийн тоо автоматаар бодогдоно.
- Үр дүнгийн текст дээр дарж засах, устгах, байрыг солих; “+ Үр дүн нэмэх”.
- **Ерөнхий мэдээлэл** — байгууллага, он, багш, батлах хүн (толгой, гарын үсэгт гарна).
- **Word татах** — сонгосон бүлгийн 7 чиглэлийг хэвтээ A4 хэлбэрийн `.doc` файл болгоно.
- **Хэвлэх / PDF** — шууд хэвлэх эсвэл PDF болгон хадгалах.
- Өөрчлөлт хөтөчид автоматаар хадгалагдана. Өөр компьютер руу шилжүүлэх, нөөцлөхдөө
  **JSON хадгалах / JSON нээх**-ийг ашиглана.
- **✏️ Сарын төлөвлөлт, үйл ажиллагаа** — 4 бүлэг тус бүрд, сар бүрээр:
  1. **Үр дүнгийн шүүлт** — жилийн төлөвлөгөөний тухайн сарын баганаас үр дүнг автоматаар
     шүүнэ (уялдаа эхэнд, давтамж дараа). Уялдааг сонгох, “Өдөр бүр” гэх мэт тэмдэглэл бичих,
     аль чиглэлийг оруулахыг (анхдагчаар Хөгжмийг оруулахгүй) сонгоно.
  2. **Хуваарь** — Да–Ба ажлын өдрүүдийг нэг товчоор үүсгэж, үр дүнг өдөр бүрт хуваарилна
     (гараар эсвэл автоматаар). “Хэрэгжүүлэх өдөр” багана хуваариас өөрөө бөглөгдөнө.
  3. **Үйл ажиллагаа** — өдөр бүрийн “Чиглүүлэгтэй үйл ажиллагааны төлөвлөлт”: арга, чадамж,
     хэрэглэгдэхүүн, үнэлгээний шалгуур, 7 үе шаттай явц (Тойргийн цаг … Хөгжөөн баясах).
  4. **Чанга уншлага** — номын мэдээлэл, шинэ үгс, 3 уншлагын асуулт, номын бичвэр.
  - Сарын бүх баримтыг (шүүлт, хуваарь, үйл ажиллагаа, чанга уншлага) нэг Word файлаар
    эсвэл өдөр тус бүрээр татах, хэвлэх боломжтой. Ахлах, Дунд, Бэлтгэл бүлгийн 9–5-р сар бөглөгдсөн.
- Алдаатай уялдаа (жагсаалтад байхгүй код), аль ч сард төлөвлөгдөөгүй үр дүнг анхааруулна.

## Бүтэц

| Файл | Үүрэг |
|---|---|
| `index.html` | Ашиглах систем (өгөгдөл шингээсэн, бэлэн файл) |
| `src/app.html` | Системийн эх код |
| `data/plan-data.json` | 2026-2027 оны 4 бүлгийн төлөвлөгөөний өгөгдөл |
| `tools/extract_docx.py` | Word (.docx) төлөвлөгөөнөөс өгөгдөл задлах |
| `data/month-*.json` | Сарын төлөвлөлтүүд: Ахлах, Дунд, Бэлтгэл (9–5-р сар) |
| `tools/extract_month.py` | Сарын төлөвлөлтийн Word файлаас өгөгдөл задлах |
| `tools/build.py` | `src/app.html` + өгөгдөл → `index.html` |

Шинэ Word файлуудаас өгөгдөл шинэчлэх:

```bash
python3 tools/extract_docx.py бага.docx дунд.docx ахлах.docx бэлтгэл.docx > data/plan-data.json
python3 tools/build.py
```
