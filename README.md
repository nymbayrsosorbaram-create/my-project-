# Хүүхдийн бүтээлийн дүгнэлт бичих систем

Цэцэрлэгийн багш хүүхдийн бүтээлд (зураг, баримал, апплекац, хийц) дүгнэлт бичихэд зориулсан програм.
Интернэтгүй ажиллана. Бүх өгөгдөл таны хөтөч (browser) дотор хадгалагдана.

## Эхлүүлэх

1. Хавтсыг компьютертээ хуулна.
2. `index.html` файлыг Chrome, Edge эсвэл Firefox-оор нээнэ.
3. **👥 Бүлэг** цэснээс цэцэрлэгийн нэр, бүлэг (Бага / Дунд / Ахлах / Бэлтгэл), хүүхдийн нэрсээ оруулна.

> Утсан дээрээс ашиглах бол GitHub Pages-д байршуулж болно (Settings → Pages → `main` салбар).

## Үнэлгээний бүтэц

**Сургалтын 7 чиглэл бүгд орсон:** Нийгэм-сэтгэл хөдлөл (НСХ), Хөдөлгөөн, эрүүл мэнд (ХЭМ), Хэл яриа (ХЯ),
Байгаль, нийгмийн орчин (БНО), Математик (МАТ), Зураг, урлал (ЗУ), Хөгжим (ХӨГ). Чиглэл бүрийн дэд ай,
I–IV түвшний суралцахуйн үр дүн, зорилго, үнэлгээний шалгуурыг хөтөлбөрийн PDF-ээс `js/program.js` руу гаргав.

Эх сурвалж: **Сургуулийн өмнөх боловсролын сургалтын хөтөлбөр (2025), 10.6 Зураг, урлал** болон
**Хүүхдийн хөгжлийн үнэлгээний арга зүй — сургалтын гарын авлага (2023)**.

- **Шалгуур:** хөтөлбөрийн суралцахуйн үр дүн (ЗУ1.1а … ЗУ4.2е), I–IV түвшин. Бүлгээс хамаарч анхдагч түвшин сонгогдох ба хүүхэд бүрээр өөрчилж болно.
- Үйл ажиллагааны төрлөөс (зураг, баримал, наамал, зохион бүтээх) хамаарч тохирох шалгуур гарна.
- Шалгуур бүрт гарын авлагын нас тус бүрийн үнэлгээний хуудасны шалгуурыг харуулна.
- **Түвшин:** Хангасан / Хэсэгчлэн хангасан / Хангаагүй; нийгэмшихүйд Байнга / Хааяа илэрнэ / Илрэхгүй.
- **Нэгтгэсэн дүн:** ≥65% «Хангалттай» (ерөнхий дэмжлэг), 36–64% «Дундаж» (нэмэлт дэмжлэг), ≤35% «Дунджаас доогуур» (тусгай дэмжлэг).
- **Үнэлгээний төрөл:** гарааны, явцын, үр дүнгийн.
- **Хувийн хавтас:** бүтээл бүрт он, сар, өдөр, нас (сараар) автоматаар бичигдэж, цаг хугацааны дарааллаар хадгалагдана.
