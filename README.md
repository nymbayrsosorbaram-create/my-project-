# Хүүхдийн бүтээлийн дүгнэлт бичих систем

Цэцэрлэгийн багш хүүхдийн бүтээлд (зураг, баримал, апплекац, хийц) дүгнэлт бичихэд зориулсан програм.
Интернэтгүй ажиллана. Бүх өгөгдөл таны хөтөч (browser) дотор хадгалагдана.

## Эхлүүлэх

1. Хавтсыг компьютертээ хуулна.
2. `index.html` файлыг Chrome, Edge эсвэл Firefox-оор нээнэ.
3. **👥 Бүлэг, хүүхэд** цэснээс цэцэрлэгийн нэр, бүлэг (Бага / Дунд / Ахлах / Бэлтгэл), хүүхдийн нэрсээ оруулна.

> Утсан дээрээс ашиглах бол GitHub Pages-д байршуулж болно (Settings → Pages → `main` салбар).

## Боломжууд

| Цэс | Юу хийх вэ |
|---|---|
| ✏️ **Дүгнэлт бичих** | Бүлэг сонгох → хүүхэд, сэдэв, төрөл оруулах → бүтээлийн **зургийг оруулах** (файлаас, камераар, чирж эсвэл Ctrl+V) → 8 шалгуураар түвшин сонгох → **⚡ Дүгнэлт автоматаар үүсгэх** → бэлэн үгсээс нэмэх, засах |
| 🗂 **Бүтээлийн сан** | Хадгалсан бүтээлүүдийг хайх, шүүх, засах; нэг болон олон бүтээлийг **Word** болон **зурагтай хэвлэх** |
| 👥 **Бүлэг, хүүхэд** | Бүлэг, насны ангилал, багш, хүүхдийн жагсаалт |
| 📚 **Үгийн сан** | Шалгуур бүрийн өгүүлбэрийг бүлэг, түвшнээр засах; шинэ шалгуур, бэлэн үг нэмэх; үгийн санг файлаар хуваалцах |
| 📖 **Хөтөлбөр, арга зүй** | Насны бүлэг бүрийн хүлээгдэж буй үр дүнгийн хүснэгт, хөтөлбөр/гарын авлагын тэмдэглэл (засах боломжтой) |
| 💾 **Нөөцлөх** | Бүх өгөгдлийг (зурагтай) нэг файлд нөөцлөх, сэргээх; бүлгийн нэгдсэн Word тайлан |

## Үнэлгээний бүтэц

- **Шалгуур (Дүрслэх урлаг):** Шугам, хэлбэр · Өнгө · Зохиомж · Багаж хэрэгсэл, техник · Бүтээлч санаа · Сэдэв, агуулга · Бүтээлээ тайлбарлах · Оролцоо, бие даалт
- **Хөгжлийн чиглэл:** Бие бялдар (нарийн хөдөлгөөн), Танин мэдэхүй, Хэл яриа, Нийгэм-сэтгэл хөдлөл, Бүтээлч чадвар
- **Түвшин:** Ахисан · Хангалттай · Дэмжлэг шаардлагатай

Бэлэн өгүүлбэрүүд нь СӨБ-ын хөтөлбөрийн дүрслэх урлагийн агуулга, хөгжлийн үнэлгээний арга зүйн
ерөнхий зарчимд тулгуурласан анхдагч хувилбар юм. Өөрийн цэцэрлэгт мөрдөж буй хөтөлбөр, гарын
авлагын яг бичвэрийг **📚 Үгийн сан** болон **📖 Хөтөлбөр, арга зүй** цэснээс оруулж болно.

## Анхааруулга

- Өгөгдөл тухайн компьютерийн хөтөч дотор хадгалагдана. Хөтчийн түүх/cookie цэвэрлэвэл устаж болзошгүй
  тул **💾 Нөөцлөх** цэснээс тогтмол нөөц файл татаж, флаш эсвэл Drive-д хадгалаарай.
- Өөр компьютерт шилжүүлэхдээ нөөц файлаа тэнд **Нөөцөөс сэргээх** хэсгээр оруулна.
